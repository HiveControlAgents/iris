# Como contribuir

1. Abra uma issue antes de mudanças grandes.
2. Rode os testes: `pip install Pillow pytest` e `pytest -q tests` (precisa de ffmpeg no PATH).
3. Comentários e mensagens em português; código simples e sem dependências novas obrigatórias.
4. Critérios novos de revisão vão em `skills/revisar-video/criterios.md`, com o valor de referência e o porquê.

## How to contribute (English)

1. Open an issue before large changes.
2. Run the tests: `pip install Pillow pytest` and `pytest -q tests` (needs ffmpeg on the PATH).
3. Comments and commit messages are in Portuguese; keep the code simple, with no new required dependencies.
4. New review criteria go in `skills/revisar-video/criterios.md`, with the reference value and the reason.
