# Como contribuir

1. Abra uma issue antes de mudanças grandes.
2. Rode os testes: `pip install Pillow pytest` e `pytest -q tests` (precisa de ffmpeg no PATH).
3. Comentários e mensagens em português; código simples e sem dependências novas obrigatórias.
4. Critérios novos de revisão vão em `skills/revisar-video/criterios.md`, com o valor de referência e o porquê.
